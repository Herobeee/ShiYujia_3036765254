# Raw data instructions

The course provides licensed stock-return and factor packages. Obtain the packages through the course's official download page before the stated deadline. For the Jegadeesh–Titman momentum project, the brief specifies Package 02 (monthly stocks and factors) and Package 03 (daily stocks).

Extract the approved packages in the local project working directory as instructed by the course, preserving numbered folder names and source filenames. See the package README and data dictionary for exact source fields and processing requirements.

**Do not commit the restricted ZIP files or their extracted CRSP/course data to this repository.** The public project should document how the authorized user can obtain the inputs and reproduce the workflow locally. This folder intentionally contains documentation only.
